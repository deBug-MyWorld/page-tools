来源与坦白

这个页面上的每一条观察，都来自你刚刚打开它那几毫秒内，你自己的浏览器。文字由人写成。下面是几条诚实的注脚。
  • 你的位置
    ip-api.com · 免费层级 · CC-BY-SA
    你的 IP 地址会出现在设备发出的每一个请求头里。我们把它交给 ip-api.com，把它换成城市和网络服务商名称。查询是瞬时的，双方都不保存。在 GDPR 下，若用于跟踪，IP 地址可被视为个人数据。我们不跟踪，不保留，不记日志。屏幕上只显示第一段和最后一段。其余部分我们知道，只是选择不显示。
  • 浏览器 API
    MDN Web Docs · Mozilla · CC-BY-SA 2.5
    关于你的设备的一切观察（屏幕、浏览器、语言、GPU、核心数、电池、字体、偏好设置）都来自 Mozilla 公开文档里定义的标准 JavaScript API。没有利用，没有漏洞，没有黑客技巧。这个页面上的一切，都是设计使然。问题就在设计本身。
  • 字体指纹
    Electronic Frontier Foundation · Cover Your Tracks (formerly Panopticlick)
    通过测量文本渲染宽度来检测已安装字体的技术，自 2010 年起就有文献记录。EFF 维护着一个工具，让你看到自己的浏览器有多独特。大多数浏览器即使完全不依赖 Cookie，也已经足够独特，能够在开放网络中被持续跟踪。字体组合是其中最强的信号之一。
  • Canvas 指纹
    Princeton University · Web Transparency & Accountability Project
    普林斯顿大学在 2014 年发表的研究，首次记录了真实世界中的 Canvas 指纹。研究者在排名前 10 万的网站里发现，5% 会偷偷让访问者的浏览器绘制一张隐藏图片，再把渲染出来的像素读回去，当成标识符。你的浏览器支持这种技术。我们没有画。你接下来打开的页面，也许会。
  • 剪贴板 API
    MDN · Clipboard API 规范
    只要有一个用户手势（一次点击、一次点按），页面就可以请求读取你最近复制过的内容。可能是密码，可能是地址，可能是一条还没发出的消息。每一个现代浏览器都会宣告自己具备这项能力。我们没有请求。能力就在那里，任何在合适时机发问的页面都能用。
  • 电池研究
    Olejnik, Englehardt, Narayanan · 2015 · "The Leaking Battery"
    发表于 Workshop on Data Privacy Management 论文集。论文证明，电量百分比和放电时间的组合已经足够独特，能够在多个网站之间追踪同一个访客，最长可达三十分钟。没有 Cookie，没有账号。Firefox 在 2016 年移除了这个 API。Chrome 和 Edge 仍然暴露它。
  • 我们没有运行的技术
    有文档记录 · 合法 · 广泛部署
    页面可以通过让你的浏览器加载其他站点的 favicon 地址，并观察哪些成功、哪些失败，来判断你登录了哪些网站。登录态和未登录态返回的图片并不一样。这个技术不需要任何权限。靠它，一个页面无需征求同意，就能知道你是否登录着 Facebook、Google、X、GitHub、Reddit、LinkedIn 以及更多服务。我们没有运行它。它有公开文档，也合法。你今天访问过的某些页面运行了。
  • 条形码
    在你的浏览器里计算 · 16 条细线 · 只属于你
    数字下方的十六根细线，高度来自你的设备交出来的数据：GPU、字体、屏幕尺寸、语言、时区、操作系统、浏览器、色深。相同数据，相同条码。不同访客，不同条码。计算发生在你的浏览器里，什么都不会被发送出去。只有拥有和你完全一样指纹的人，才会看到相同的线。这个概率很小。
  • 文字
    手写 · 基于模板，不是生成式
    这个页面上的每一句话都由 Matt 写成。代码会根据浏览器返回的数据，从现成的文字模板中挑选。运行时没有任何语言模型负责写作或改写。如果某种情况没有被手写文案覆盖，页面就对它保持沉默。我们宁可少说，也不愿说错。
  • 这个页面发送了什么
    两个匿名事件到我们的服务器
    两个事件：你来了，你读完了。没有 Cookie，没有标识符，不保留 IP。我们的服务器会丢弃每次请求的 body，也不返回任何东西。请求发生过这件事，仍会作为传输层记录存在于托管商日志里，直到他们的默认保留期结束，通常是几天。不是我们配置的。你访问的每个网站都会有同样的记录。区别在于，大多数网站还会额外向广告商、指纹采集方、会话回放工具和标签管理器发送数百个信标。我们只发两个，发给自己，并且告诉你。
  • 这个页面在你的设备上存了什么
    什么都没有
    没有 Cookie。没有 localStorage。没有 sessionStorage。没有 IndexedDB。没有 service worker 缓存。你看到的数据都在你的浏览器里算出，从未离开你的设备，除了 IP 地理位置查询，以及上面那两个匿名事件。你一关闭这个标签页，这个页面就会忘记你存在过。今天你访问的页面里，能诚实说出这句话的，我们大概是唯一一个。
